# v2.5.0

## 个人多 Agent 工作流

- 增加 Claude 状态卡片，显示插件可确认的引擎、任务状态、项目 session 短 id 和最近用途。
- 增加「规划 / 执行 / 审查」个人任务模式，分别控制本机自动监工和手动验收策略。
- 增加当前项目 Claude session 的显式 Fork；下一次 CLI/SDK 调用基于原 session 创建分支，原 session 保持不变。
- 保持同一项目普通规划流程的 session 复用、全局监工独立只读 session，以及 Claude Desktop 仅用于人工确认。
- 不引入多人 caller、远程 relay 或公网通信。

## 界面与验证

- 修复 Claude 状态卡在窄屏和宿主层叠样式下可能被覆盖的问题。
- 个人模式、session Fork、CLI/SDK fork 选项和现有流程均加入回归测试。
- 全量 acceptance 测试：192/192 通过。
